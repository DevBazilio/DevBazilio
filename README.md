# 👋 Hey there, I'm Yurii (DevBazilio)

**Node.js Backend & Full-Stack Developer** focused on high-performance APIs, distributed systems, and complex Discord/Telegram bot ecosystems.

---

### 💫 About Me

- 🔭 **What I’m working on:** Architecting scalable backend systems, full-stack web management platforms, and high-load Discord/Telegram bots using **Node.js (Fastify)**, **MongoDB**, **Redis**, and **RabbitMQ**.
- 🌱 **Currently exploring:** Multi-server Docker orchestration, distributed observability (**OpenTelemetry**, **Prometheus**, **Grafana**), and self-hosted Linux VPS infrastructure.
- ⚙️ **Architecture & Ops:** Experienced with event-driven microservices, message queues, caching strategies, and secure mesh networking across multi-node Linux environments.
- ⚡ **Fun fact:** I love turning complex server administration into automated workflows—complete with real-time Telegram alerts and custom SSH terminal setups.
